=>How to export an excel sheet with laravel exce.

    To export an Excel sheet in Laravel, you can use the popular package Laravel Excel, built on Maatwebsite Excel.

    ✅ Step-by-step guide to export an Excel file in Laravel:
    Step 1: Install Laravel Excel

    Run this in your Laravel project:

    composer require maatwebsite/excel
    Step 2: Create an Export Class
    php artisan make:export UsersExport --model=User

    This will create UsersExport.php in App\Exports.

    Step 3: Define the Export Logic

    Edit App\Exports\UsersExport.php:

    namespace App\Exports;


    use App\Models\User;
    use Maatwebsite\Excel\Concerns\FromCollection;


    class UsersExport implements FromCollection
    {
        public function collection()
        {
            return User::all(); // Or add ->select('id', 'name', ...) to limit columns
        }
    }

    Other interfaces you can use:

    FromArray – if you want to pass array manually
    WithHeadings – for column headers
    WithMapping – to format data
    FromView – if you want to use a Blade view
    Step 4: Create the Export Route and Controller Method

    In web.php:

    use App\Http\Controllers\UserExportController;


    Route::get('/export-users', [UserExportController::class, 'export']);

    Create controller if you don't have:

    php artisan make:controller UserExportController

    In UserExportController.php:

    namespace App\Http\Controllers;


    use App\Exports\UsersExport;
    use Maatwebsite\Excel\Facades\Excel;


    class UserExportController extends Controller
    {
        public function export()
        {
            return Excel::download(new UsersExport, 'users.xlsx');
        }
    }
    ✅ Optional: Add Headings

    In your UsersExport.php, implement WithHeadings:

    use Maatwebsite\Excel\Concerns\WithHeadings;


    class UsersExport implements FromCollection, WithHeadings
    {
        public function collection()
        {
            return User::select('id', 'name', 'email')->get();
        }


        public function headings(): array
        {
            return ['ID', 'Name', 'Email'];
        }
    }
    ✅ Optional: Export with Blade View (for complex layout)

    Use FromView instead of FromCollection:

    use Illuminate\Contracts\View\View;
    use Maatwebsite\Excel\Concerns\FromView;


    class UsersExport implements FromView
    {
        public function view(): View
        {
            return view('exports.users', [
                'users' => User::all()
            ]);
        }
    }

    And create resources/views/exports/users.blade.php as a normal HTML table.

    ✅ Output as CSV
    return Excel::download(new UsersExport, 'users.csv', \Maatwebsite\Excel\Excel::CSV);

    How to use from collection.

    To use FromCollection in Laravel Excel for your Employees Export, follow these steps. This method enables true auto-width, since FromCollection works directly with spreadsheet cells instead of rendering an HTML view.

    ✅ Step-by-Step: Use FromCollection
    🧩 1. Update Your Export Class

    Here’s a full example using FromCollection, WithHeadings, and ShouldAutoSize:

    <?php


    namespace App\Exports;


    use Illuminate\Support\Collection;
    use Maatwebsite\Excel\Concerns\FromCollection;
    use Maatwebsite\Excel\Concerns\ShouldAutoSize;
    use Maatwebsite\Excel\Concerns\WithTitle;
    use Maatwebsite\Excel\Concerns\WithHeadings;


    class EmployeesExport implements FromCollection, WithTitle, ShouldAutoSize, WithHeadings
    {
        private $employees;


        public function __construct($employees)
        {
            $this->employees = $employees;
        }


        public function title(): string
        {
            return 'Employees List';
        }


        public function headings(): array
        {
            return [
                'No',
                'Name',
                'Employee Code',
                'Branch',
                'Position',
                'Level',
                'Criteria 1',
                'Criteria 2',
                'Criteria 3',
                'Criteria 4',
                'Criteria 5',
            ];
        }


        public function collection(): Collection
        {
            return collect($this->employees)->map(function ($employee, $index) {
                $criteria = $employee->emppuser?->getAssFormCats() ?? [];


                // Get up to 5 criteria names, pad with empty strings if less
                $criteriaNames = collect($criteria)
                    ->pluck('name')
                    ->take(5)
                    ->pad(5, '');


                return [
                    $index + 1,
                    $employee['employee_name'],
                    $employee['employee_code'],
                    $employee['branch']['branch_name'],
                    $employee->position->name,
                    $employee->positionlevel->name,
                    $criteriaNames[0],
                    $criteriaNames[1],
                    $criteriaNames[2],
                    $criteriaNames[3],
                    $criteriaNames[4],
                ];
            });
        }
    }
    🧠 Explanation
    ✅ FromCollection: Returns data as a collection (like a table).
    ✅ WithHeadings: Adds a header row at the top.
    ✅ ShouldAutoSize: Makes all columns auto-width correctly.
    ✅ WithTitle: Adds the sheet name if exporting multiple sheets.

            public function collection()
            {
                $data = collect();
                $this->imagePaths = []; // Reset image storage
                $rowCounter = 2; // Start from row 2 (first row is the heading)
                $totalDamageQty = 0; // Initialize total qty

                foreach ($this->sourcingDocuments->sortByDesc('id') as $document) {
                    foreach ($document->sourcingproduct->sortBy('id') as $product) {
                        $excelRowIndex = $rowCounter; // Keep track of the row index for images

                        // **Group images by 'row' value**
                        $groupedImages = $product->sourcingproductimage->groupBy('row');

                        foreach ($groupedImages as $rowKey => $images) {
                            $imageColumnIndex = ord('F'); // Start inserting images from column F

                            foreach ($images as $image) {
                                $imagePath = public_path("storage/" . $image->media_link);
                                if (!file_exists($imagePath)) {
                                    $imagePath = public_path("storage/" . getSourcingImage($image));
                                }

                                if (file_exists($imagePath)) {
                                    $coordinates = chr($imageColumnIndex) . $excelRowIndex; // Convert back to letter
                                    $this->imagePaths[] = [
                                        'path' => $imagePath,
                                        'coordinates' => $coordinates,
                                    ];
                                    $imageColumnIndex++; // Move to next column for next image
                                }
                            }

                            // **Push product row**
                            $data->push([
                                'Document No'   => $document->document_no,
                                'Product Name'  => $product->product_name,
                                'Product Code'  => (string) $product->product_code_no,
                                'Branch'        => $document->branches->branch_name,
                                'Damage Qty'    => $image->seperate_qty,
                                '', '', '', '', '', '', '', // Empty placeholders for images (F to L)
                                'Brand' => $product->product_brand_name,
                                'Remark' => $product->remark ?? '', // Ensure "Remark" is at column M
                                'PL/PI No' => $document->car_no
                            ]);

                            // **Update total damage quantity**
                            $totalDamageQty += $image->seperate_qty;

                            $excelRowIndex++; // Move to the next row for the next group of images
                            $rowCounter++; // Ensure rowCounter is also updated
                        }
                    }
                }

                // **Add "Total" row at the end**
                $data->push([
                    'Document No'   => '', // Empty
                    'Product Name'  => '',
                    'Product Code'  => '',
                    'Branch'        => 'Total', // "Total" label in the Branch column
                    'Damage Qty'    => $totalDamageQty, // Total sum of Damage Qty
                    '', '', '', '', '', '', '', // Empty placeholders for images
                    'Brand' => '',
                    'Remark' => '', // Remark empty for total row
                    'PL/PI No' => ''
                ]);

                $this->totalRows = $rowCounter; // Update total row count

                return $data;
            }

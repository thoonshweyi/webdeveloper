bar code, qr code ထုတ်တာ အဆင့်ဆင့်ပြောပြပါ။

ရပါတယ်။ သင့် case မှာ PO document_no တစ်ခုတည်းကို source အဖြစ်သုံးပြီး Barcode + QR Code နှစ်ခုလုံး generate → SVG file သိမ်း → DB မှာ path သိမ်း → PDF print တိုင်း saved SVG ကိုသုံး မယ်။

အဆင့်လိုက်သွားရအောင်။

Flow တစ်ခုလုံး

   ↓
document_no

   ├── Barcode SVG generate

   │   storage/barcodes/xxx.svg
   │
   └── QR SVG generate
           ↓
       storage/qrcodes/xxx.svg

   ↓

Step 1 — Barcode package install

Barcode အတွက် picqer/php-barcode-generator သုံးပါ။

composer require picqer/php-barcode-generator

စစ်ရန်—

composer show picqer/php-barcode-generator
Step 2 — QR Code package install

QR အတွက် Laravel မှာ သင်အရင်သုံးဖူးတဲ့ SimpleSoftwareIO/simple-qrcode ကို သုံးလို့ရပါတယ်။

composer require simplesoftwareio/simple-qrcode

စစ်ရန်—

composer show simplesoftwareio/simple-qrcode
Step 3 — PO table မှာ path column နှစ်ခုထည့်

ပြီးရင်—

Step 5 — Barcode + QR generate service တစ်ခုလုပ်

ကျွန်တော်က Controller ထဲမှာ code အများကြီးထည့်မယ့်အစား Service တစ်ခုလုပ်ဖို့ အကြံပြုပါတယ်။

php artisan make:class Services/DocumentCodeService

မရတဲ့ Laravel version ဆိုရင် file ကို manually—

app/Services/DocumentCodeService.php

လုပ်ပါ။

ပြီးရင်—

<?php

namespace App\Services;

use Illuminate\Support\Facades\Storage;
use Picqer\Barcode\BarcodeGeneratorSVG;
use SimpleSoftwareIO\QrCode\Facades\QrCode;

class DocumentCodeService
{
    public function generate(string $documentNo): array
    {
        $safeName = str_replace(['/', '\\'], '-', $documentNo);

        /*
         * Barcode
         */
        $barcodeGenerator = new BarcodeGeneratorSVG();

        $barcodeSvg = $barcodeGenerator->getBarcode(
            $documentNo,
            BarcodeGeneratorSVG::TYPE_CODE_128
        );

        $barcodePath = "barcodes/{$safeName}.svg";

        Storage::disk('public')->put(
            $barcodePath,
            $barcodeSvg
        );

        /*
         * QR Code
         */
        $qrSvg = QrCode::format('svg')
            ->size(300)
            ->margin(0)
            ->generate($documentNo);

        $qrPath = "qrcodes/{$safeName}.svg";

        Storage::disk('public')->put(
            $qrPath,
            $qrSvg
        );

        return [
            'barcode_path' => $barcodePath,
            'qr_code_path' => $qrPath,
        ];
    }
}

    ↓
Barcode SVG
    ↓

document_no
    ↓
QR SVG

Step 7 — PO create လုပ်တဲ့နေရာမှာ generate

ဥပမာ သင့် Controller မှာ PO create ပြီးတဲ့နောက်—

use App\Services\DocumentCodeService;

ပြီးရင်—

$po = PurchaseOrder::create([
    // your PO data
]);

ပြီးတဲ့နောက်—

$codeService = app(DocumentCodeService::class);

$paths = $codeService->generate(
    $po->document_no
);

$po->update($paths);

အဲ့ဒီအချိန်မှာ DB က—

ဒီ architecture က print တိုင်း generate မလုပ်ဘဲ create တုန်းက တစ်ခါ generate လုပ်ထားပြီး PDF မှာ saved file ကိုပဲသုံးတာ ဖြစ်ပါတယ်။

တစ်ချက်သတိထားရန်: document_no ကို နောက်ပိုင်း edit/change လုပ်ခွင့်ရှိရင် document_no ပြောင်းတဲ့အချိန်မှာ Barcode + QR ကိုလည်း regenerate လုပ်ရပါမယ်။ document_no က immutable ဖြစ်ရင် အခု design အတိုင်း အဆင်ပြေပါတယ်။
